## [0.1.0] — 2026-10-28

Первый публичный выпуск. Проект вырос из внутренней замены iRedMail и обкатан на действующем стенде
(сквозная доставка, IMAP, DKIM, DANE, миграция ~4,5 ГБ почты).

### Добавлено
- Postfix 3.10 + Dovecot 2.4 + Rspamd + ClamAV на PostgreSQL: домены, ящики, алиасы, catch-all, доменные
  алиасы, рассылки, квоты, режимы ящиков, автоответ, пересылка, BCC, Sieve.
- Бэкенд FastAPI с REST API (`docs/api.md`), CLI (`python -m app.cli`), журналом аудита и ролями
  superadmin / domain_admin; локальные пароли администраторов.
- Панель администрирования (Vue 3 + PrimeVue): сводки, дашборд домена с проверкой DNS, очередь, состояние хоста
  с графиками, настройки сервера по белому списку, спам-фильтр, аудит; личный кабинет пользователя.
- Агент на хосте с белым списком команд в sudoers (регулярные выражения sudo).
- Необязательная интеграция с Active Directory: вход админов, пароли ящиков по LDAPS, синхронизация ящиков и
  рассылок; скрипт выпуска сертификата LDAPS на контроллере (`tools/ad-ldaps-cert.ps1`).
- Установка на чистый Debian 13 одним идемпотентным скриптом, деплой по SSH, Let's Encrypt через certbot или
  сертификат с другого хоста, nftables, fail2ban, systemd-песочницы, защита входа от перебора (Redis + nginx).
- Миграция с iRedMail: выгрузка, импорт доменов/ящиков/пересылок/DKIM, раскладка Maildir'ов.
- Документация: установка, настройка, эксплуатация, архитектура, безопасность, AD, веб-почта, миграция.
