# Безопасность

## Сообщить об уязвимости

Не открывайте публичный issue с деталями. Используйте приватное сообщение в GitHub
(Security → Report a vulnerability) или откройте issue с пометкой «security» без подробностей — сопровождающий
свяжется с вами. Укажите версию (коммит), шаги воспроизведения и, если есть, предлагаемое исправление. Ответ — в течение 7 дней; исправление критичных уязвимостей публикуется отдельным выпуском с записью
в `CHANGELOG.md`.

## Поддерживаемые версии

Исправления выходят для последней минорной версии. Сами почтовые демоны (Postfix, Dovecot, Rspamd, ClamAV, nginx,
PostgreSQL, Redis) берутся из Debian и обновляются через `apt` и `security.debian.org` — это ответственность
администратора сервера (см. `docs/operations.md`).
