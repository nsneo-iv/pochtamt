# Миграция с iRedMail

Переносится: домены, ящики (хеши паролей как есть), алиасы и пересылки, доменные алиасы, Maildir'ы (с флагами и
`dovecot-uidlist` — клиенты не перекачивают письма), ключи DKIM с прежним селектором (DNS менять не нужно).
Не переносится: админы iRedMail (их заводят заново: `admin-add`), настройки Amavis/SpamAssassin (спам-фильтр —
Rspamd), mlmmj-рассылки (в новой модели — `lists`), пользовательские правила Sieve.

На старом сервере выполняются **только чтение и копирование**; рабочая почта продолжает идти через него до
переключения. Схема обкатана на переносе ~4,5 ГБ / 33 ящика / 3 домена.

## Порядок

1. **Выгрузка** (на старом сервере, root): `bash install/migrate/iredmail-export.sh /root/iredmail-export` —
   TSV из базы `vmail` (MySQL/MariaDB; в файлах хеши паролей, каталог 0700). Ключи DKIM iRedMail лежат в
   `/var/lib/dkim/<домен>.pem`, селектор у iRedMail — `dkim`.
2. **Канал**: на новом сервере в `~<VM_USER>/.ssh/authorized_keys` — временный ключ старого сервера с ограничением
   `restrict,from="<ip старого>",command="/usr/bin/rrsync -wo /srv/migrate"` (только запись в `/srv/migrate`);
   ключ генерируется на старом (`ssh-keygen -t ed25519 -N ''`), отпечаток нового хоста закрепляется в `known_hosts`.
   `rsync` на новом сервере ставит `install.sh`.
3. **Копирование** (со старого): `rsync -a --bwlimit=40000 --exclude 'dovecot.index*' --exclude 'dovecot.list.index*'
   /var/vmail/vmail1/<домен> <VM_USER>@<новый>:/vmail1/` под `ionice -c3 nice -n19` (индексы Dovecot 2.3 не
   переносятся — 2.4 построит свои). Туда же `/root/iredmail-export/` и `/var/lib/dkim/*.pem` (в `/dkim/`).
4. **Импорт в базу** (на новом, из `/opt/mail/backend`, под `mailapp`; файлы временно в каталоге с группой
   `mailapp`, например `/run/mailimp`):
   ```
   python -m app.cli import-iredmail /run/mailimp                         # предпросмотр
   python -m app.cli import-iredmail /run/mailimp --apply
   python -m app.cli import-dkim /run/mailimp --selector dkim --apply     # ключи с прежним селектором
   ```
   Импорт идемпотентен (upsert); пересылки iRedMail с самокопией становятся `keep_copy`; хеши `{SSHA512}`,
   `{SSHA}`, bcrypt, `$6$`/`$5$` переносятся как есть, остальное — в предупреждения.
5. **Раскладка Maildir'ов** (root): `python3 install/migrate/place-maildirs.py /srv/migrate [--apply]`
   (`vmail1/<maildir>/Maildir` → `/var/vmail/<домен>/<ящик>/Maildir`, владелец `vmail`, индексы отбрасываются,
   пути проверяются на выход за каталог).
6. **Проверка**: `doveadm mailbox list -u <ящик>`, `doveadm search -u <ящик> all | wc -l`, вход IMAP; сравнить
   число писем с `doveadm` на старом.
7. **Убрать канал**: ключ из `authorized_keys`, на старом сервере — временный ключ и `/root/iredmail-export`,
   на новом — `/srv/migrate/*`.

## Пароли

Хеши `{SSHA512}` Dovecot проверяет сам, вход в IMAP работает сразу. При входе в личный кабинет (`/me`) хеш
заменяется на bcrypt (`{BLF-CRYPT}`) — пароль известен только в этот момент. `{SSHA}` (SHA-1) попадает в
предупреждения импорта: таким пользователям стоит сменить пароль. С AD: перевести ящики на `auth = ad`.

## Переключение (cutover)

Заранее: уменьшить TTL записей MX и A до 300 с; PTR внешнего IP = `MAIL_HOSTNAME`; `mynetworks` на новом сервере
= как на старом (панель «Сервер → Параметры»); внешние устройства и службы, отправляющие почту без авторизации,
перенастроены или добавлены в `mynetworks`; веб-почта (если есть) смотрит на новый сервер.

1. Остановить приём на старом (`systemctl stop postfix` или перенаправить 25 на новый).
2. Повторить копирование целиком с `--delete`, стереть `/var/vmail/<домен>` ящиков на новом и выполнить
   раскладку заново — так флаги, UID и удаления совпадут точно (дельта «на лету» намеренно не используется).
3. Перенаправить 25/465/587/993/4190 и MX на новый сервер; проверить входящую и исходящую, DKIM у получателя.
4. Старый сервер оставить выключенным на 2–4 недели.

## Грабли, найденные при реальной миграции

- Каталоги Maildir у ящиков, которым не приходила почта, на старом сервере отсутствуют — Dovecot создаст их при
  первой доставке; `place-maildirs.py` такие ящики пропускает с сообщением.
- Жёсткий `storage_size` в блоке `quota` Dovecot перекрывал квоту из базы и резал все ящики до одного размера —
  в шаблоне блок пустой, значение берётся из `mailboxes.quota_mb` (0 = без ограничения).
- Старые ключи DKIM бывают RSA-1024: после переноса выпустить в панели новый 2048 с другим селектором,
  опубликовать TXT, затем переключить.
- `mysql --batch --raw` пишет `NULL` строкой — импорт считает её пустым значением.
