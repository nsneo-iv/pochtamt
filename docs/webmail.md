# Веб-почта

Pochtamt намеренно не включает веб-клиент: разбор MIME и рендер чужого HTML — самое уязвимое место любой
веб-почты, и держать его на одном хосте с почтовой базой и панелью не хочется. Рекомендуемая схема —
Roundcube (из пакетов Debian) на **отдельном хосте**, который ходит к Pochtamt как обычный почтовый клиент.

```
   пользователи ──https──▶ webmail-хост (Roundcube, своя PostgreSQL) ──IMAP 993 / SMTP 587 / Sieve 4190──▶ Pochtamt
```

У такого хоста нет доступа ни к базе почты, ни к API панели, ни к хосту почтового сервера: компрометация
веб-почты даёт не больше, чем компрометация любого почтового клиента. Вход — адрес ящика и пароль; пароль
проверяет Dovecot, поэтому локальные пароли и учётки AD работают одинаково.

## Настройка Roundcube (ключевые строки `config.inc.php`)

```php
$config['imap_host'] = 'ssl://mail.example.com:993';
$config['smtp_host'] = 'tls://mail.example.com:587';
$config['smtp_user'] = '%u';
$config['smtp_pass'] = '%p';
$config['plugins']   = ['managesieve', 'archive', 'markasjunk', 'zipdownload'];
$config['managesieve_host'] = 'tls://mail.example.com:4190';
$config['product_name'] = 'Почта';
$config['des_key'] = '…24 символа…';          // openssl rand -base64 18
```

Имя `mail.example.com` должно совпадать с именем в сертификате Pochtamt. Если внутри сети оно резолвится на
внешний адрес или обратный прокси, закрепите его в `/etc/hosts` webmail-хоста на внутренний IP почтового сервера.

## Что учесть на стороне Pochtamt

- **ManageSieve (4190) открыт только из `LAN_NETS`** — webmail-хост должен быть в этих сетях (или добавьте его
  адрес в `LAN_NETS` и выполните `install.sh`). IMAP 993 и submission 587 открыты отовсюду.
- **fail2ban не банит `LAN_NETS`**: иначе пять неудачных входов разных пользователей через веб-почту забанили
  бы весь webmail-хост. Защиту от перебора на самом webmail-хосте делает его fail2ban по логу Roundcube
  (`/var/log/roundcube/errors.log`, фильтр `roundcube-auth`).
- Dovecot видит подключения с адреса webmail-хоста (`rip=`); реальный IP пользователя будет только в логах
  Roundcube. Для `mail_max_userip_connections` это один IP на всех — лимит по умолчанию 20 может потребовать
  увеличения («Сервер → Параметры»).
- Ссылка на веб-почту в личном кабинете: `VITE_WEBMAIL_URL` в `frontend/.env` при сборке фронта.

## Публикация наружу

Веб-почту обычно публикуют через обратный прокси (nginx, HAProxy) с TLS и WAF-правилами; на самом webmail-хосте
порт 80 открывают только для прокси, 443 — для внутренней сети. Панель Pochtamt наружу не публикуют никогда.
