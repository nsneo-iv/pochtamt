# Pochtamt — заметки для Claude Code и других ИИ-ассистентов

Правила проекта — в [`CONTRIBUTING.md`](CONTRIBUTING.md); здесь только то, что важно при автоматических правках.

- Секреты — только в `.env` своей папки (`install/`, `backend/`, `agent/`, `frontend/`), в git не попадают.
  Никаких паролей в коде, комментариях, README. Новый ключ → `.env.example` той же папки с комментарием на русском.
- Бэкенд пишет только в PostgreSQL и Redis, на хост не ходит. Команды на хосте — только через `agent/`
  с белым списком в sudoers. Не добавлять бэкенду доступ к файлам или шеллу.
- Postfix и Dovecot читают только представления `v_postfix_*` / `v_dovecot_*` под ролями `mail_postfix` /
  `mail_dovecot`. Меняешь схему — сохраняй контракт представлений.
- Шаблоны конфигов содержат плейсхолдеры `@KEY@`; новый ключ → `install/.env.example` и список `TEMPLATES`
  в `install/render.py`, если это новый файл. Производные ключи считаются в `render.py`.
- Меняешь API — правь `docs/api.md` и фронт в одном коммите. После добавления файла — строка в README папки.
- Все комментарии, докстринги, README, `.env.example` и тексты интерфейса — на русском.
- `.sh` — с LF, `.ps1` — UTF-8 с BOM и CRLF (`.gitattributes`). Python 3.11+, ruff (120 символов).
  Фронт — Vue 3 + TypeScript + PrimeVue, версии зафиксированы точно.
- Перед коммитом работает `tools/check_secrets.py` (ставится `python tools/check_secrets.py --install`).
  Если он сработал — вынести значение в `.env`, а не обходить проверку.
- Dovecot в шаблонах — версии 2.4 (Debian 13); синтаксис отличается от 2.3, проверять `doveconf -n` на стенде.
- Active Directory необязателен: пустой `AD_LDAP_URI` выключает его везде (бэкенд, Dovecot, таймер, фронт через
  `GET /auth/config`). Новая функциональность должна работать в обоих режимах.
